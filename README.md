# Crossword brand

The Crossword brand system, built by PIXELUP.

| Folder | What it is |
|---|---|
| [`storybook/`](storybook/) | The brand guidelines site, live at https://crossword-brand-guidelines.vercel.app. A static site with no build step; see its README to run or deploy it. |
| [`crossword-brand-kit/`](crossword-brand-kit/) | The brand kit: `brand.md` (the operating document), `DESIGN.md` (the token contract), logo masters and exports, textures, patterns, tokens and preview sheets. |
| `crossword-brand-kit.zip` | The kit as a single download. |

The Figma source is [-For Work- Crossword](https://www.figma.com/design/TiAeD9ICNjjC8N3zoUJExk/-For-Work--Crossword): the brandbook (`2280:186`), Logo All Variants (`2270:31448`) and the layout library page (`2315:53`).

When `brand.md` and `DESIGN.md` disagree, `DESIGN.md` wins.
